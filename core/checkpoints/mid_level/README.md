# Mid-Level Checkpoints

This directory stores canonical mid-level skill checkpoints that are important
enough to treat as project assets instead of leaving them buried in `logs/`.

Current contents are only a small representative subset.

Recommended usage:

- keep full training histories in `logs/ckpt/`
- copy a few stable or representative checkpoints here for explicit reuse

Current representative policy family:

- `chaseBall`
- `passBall`
