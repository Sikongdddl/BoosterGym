# Core Checkpoints

This directory stores canonical pretrained weights that are important to the
current BoosterGym workflow.

Unlike `logs/`, this directory is meant for reusable inference-time assets.

Current groups:

- `low_level/`: locomotion checkpoints
- `mid_level/`: representative skill checkpoints
- `high_level/`: BC and RL tactical checkpoints

Current representative mid-level groups:

- `mid_level/chaseBall/`
- `mid_level/passBall/sac/`
