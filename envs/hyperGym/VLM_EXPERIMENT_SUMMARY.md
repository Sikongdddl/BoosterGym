# VLM Zero-Training Experiment Summary

## Goal

本次实验要回答的问题是：

- 在没有任何训练的情况下，VLM 能不能在 `hyperGym` 中给出对我们有用的高层战术建议
- 这些建议是否符合基本的人类直觉

## VLM Input

本次实验里，VLM 每一步接收两类输入：

- 图像输入
  - 使用 `hyperGym` 当前时刻的渲染帧
  - 图像是主输入
- 文本输入
  - 当前状态摘要
  - 包括球的位置、球速度、控球方、离球最近的双方球员、到对方球门的距离、最近事件

输入设计的核心是：

- 让模型主要看场上空间关系和相对位置
- 用简短文本补充动态信息和局面摘要

## VLM Output

VLM 输出结构化高层动作：

- `policy_id`
  - `move_to_target`
  - `pass_to_target`
  - `trap_ball`
  - `dribble_to_target`
- `target`
  - 一个二维目标点
- `reason`
  - 简短理由

这些输出随后映射成环境里的高层动作，而不是直接输出底层控制命令。

## Experiment Settings

模型与接口：

- 模型：`qwen3vl`
- 接口：`https://models.sjtu.edu.cn/api/v1`

实验分成三类：

### 1. 单步 benchmark

用于判断：

- 在典型局面下，模型给出的战术建议是否像人

覆盖的局面包括：

- 开局自由球
- 缓慢滚动的自由球
- 对手更接近自由球
- 中场控球
- 门前控球
- 2v2 控球观察空位

### 2. 默认开局 rollout

用于判断：

- 从正常开局连续多步决策时，模型会不会稳定

### 3. 控球起手 rollout

用于判断：

- 在“我方已经控球”的情况下，模型能不能连续给出推进类建议

## Main Results

### 单步 benchmark

初始结果：

- `4/6`

主要问题：

- 在“我方已经控球”的局面下，模型有时仍会给出过度保守的 `trap_ball`

调整约束后：

- `6/6`

这说明：

- 模型在单步典型局面中能够理解基本战术语义
- 它不是只能输出形式正确的 JSON，而是能根据局面区分
  - 自由球先停球
  - 已控球继续推进

### 默认开局 rollout

结果特征：

- 大部分建议都集中在 `trap_ball`
- fallback 很低
- 但整局很容易长期停留在“抢自由球/停球”阶段

这说明：

- 模型在默认开局下会优先解决最直接的问题，即先处理自由球
- 这种行为不算错误，但会掩盖它在更高层进攻组织上的能力

### 控球起手 rollout

结果特征：

- 大多数步骤会连续给出 `dribble_to_target`
- fallback 很低
- 多个 seed 下表现一致

这说明：

- 一旦进入“我方已控球”的局面，模型能持续给出向前推进的高层建议
- 这种输出是有连续性的，不是单步偶然猜对

## What The Outputs Show

从实际输出看，VLM 已经表现出一定作用，但作用范围目前是有限的。

它已经能起作用的部分：

- 识别自由球局面，优先建议停球或拿球
- 识别我方已控球局面，建议继续推进
- 在固定典型场景下给出符合基本足球直觉的高层意图

它还不够强的部分：

- 默认开局时容易长期停留在“先停球”的保守策略
- 输出目标点仍然偏保守
- 还没有充分体现更成熟的组织进攻能力
  - 例如更主动地利用空位
  - 更明确地选择传球而不是持续带球

## Conclusion

这次实验支持的结论是：

- 零训练 VLM 不是无效的
- 它已经能够在部分关键场景中输出有用的高层战术建议

更准确地说：

- 对“自由球处理”和“已控球后继续推进”这两类问题，VLM 已经表现出可用性
- 对“整局稳定组织进攻”这件事，目前证据还不够

因此当前更合适的判断不是：

- “VLM 已经可以直接当完整高层策略”

而是：

- “VLM 已经能作为高层战术建议源，在一些关键子问题上起到作用”

## Bottom Line

一句话总结：

- 从这次实验的输出来看，零训练 `qwen3vl` 在 `hyperGym` 里已经能起到一定作用，尤其体现在自由球处理和控球推进上；但它距离整局稳定、完整可用的高层战术策略还差一段。
