# VLM Zero-Training Experiment Summary

## Goal

本次实验要回答的问题是：

- 在没有任何训练的情况下，VLM 能不能在 `hyperGym` 中给出对我们有用的高层战术建议
- 这些建议是否符合基本的人类直觉

## VLM Input

本次实验里，VLM 每一步接收两类输入：

- 图像输入
  - 使用 `hyperGym` 当前时刻的渲染帧
  - 图像是主输入
- 文本输入
  - 当前状态摘要
  - 包括球的位置、球速度、控球方、双方所有球员的位置、离球最近的双方球员、到对方球门的距离、最近事件

输入设计的核心是：

- 让模型主要看场上空间关系和相对位置
- 用简短文本补充动态信息和局面摘要

当前调用频率：

- 在 `rollout` 类实验中，VLM 是**每 1 个环境 step** 接收一次输入，并推理一次新的多人动作
- 也就是说当前没有动作复用窗口，环境每推进一步，都会重新渲染当前帧并重新调用一次 VLM
- 在 oracle correctness 实验中，不是在线每步调用，而是从 oracle trajectory 中抽样状态帧做离线对比

## VLM Output

VLM 输出的是 `home` 队每个球员各自的结构化高层动作：

```json
{
  "players": {
    "home_0": {
      "policy_id": "...",
      "target": [x, y],
      "reason": "..."
    },
    "home_1": {
      "policy_id": "...",
      "target": [x, y],
      "reason": "..."
    }
  }
}
```

每个球员的 `policy_id` 仍然来自同一组高层子策略：

- `move_to_target`
- `pass_to_target`
- `trap_ball`
- `dribble_to_target`

这些输出随后映射成环境里的高层动作，而不是直接输出底层控制命令。

## Experiment Structure

模型与接口：

- 模型：`qwen3vl`
- 接口：`https://models.sjtu.edu.cn/api/v1`


- 第一批实验：初步可行性检验
  - 目标是确认零训练 VLM 在 `hyperGym` 里是不是完全不可用
  - 这些实验的权重应当较低，主要用于判断“值不值得继续做”
- 第二批实验：和 oracle trajectory 的正确性对比
  - 目标是更直接地量化 VLM 输出和标准答案之间的差距
  - 这批实验比第一批更适合用来支撑当前阶段的结论

### 第一批实验：初步可行性检验

第一批实验包含三类设置：

### 1. 单步 benchmark

用于判断：

- 在典型局面下，模型给每个 `home` 球员分配的战术建议是否像人

覆盖的局面包括：

- 开局自由球
- 缓慢滚动的自由球
- 对手更接近自由球
- 中场控球
- 门前控球
- 2v2 控球观察空位

### 2. 默认开局 rollout

用于判断：

- 从正常开局连续多步决策时，模型会不会稳定

当前设置：

- 每 `1` 个环境 step 调用一次 VLM

### 3. 控球起手 rollout

用于判断：

- 在“我方已经控球”的情况下，模型能不能连续给出推进类建议

当前设置：

- 每 `1` 个环境 step 调用一次 VLM

## Batch 1 Results: Feasibility Only

这一批实验的意义主要是：

- 检查零训练 VLM 是否具备最基本的战术语义
- 判断这条路线是否值得继续投入

它们不应该被当作当前阶段最主要的量化结论来源。

### 单步 benchmark

初始结果：

- `4/6`

主要问题：

- 在“我方已经控球”的局面下，主控球球员有时仍会给出过度保守的 `trap_ball`

调整约束后：

- `6/6`

这说明：

- 模型在典型局面中已经能给不同 `home` 球员输出彼此区分的动作
- 它不是只能输出形式正确的 JSON，而是能根据局面区分
  - 主控球球员负责停球、带球或处理球
  - 非控球球员负责跑位、支援或补位

### 默认开局 rollout

结果特征：

- 默认开局时，主接球队员的大部分建议都集中在 `trap_ball`
- 其余队友多数是跟随或保持支援位置
- fallback 很低
- 但整局很容易长期停留在“抢自由球/停球”阶段

这说明：

- 模型在默认开局下会优先解决最直接的问题，即先处理自由球
- 这种行为不算错误，但会掩盖它在更高层进攻组织上的能力

### 控球起手 rollout

结果特征：

- 主控球球员大多数步骤会连续给出 `dribble_to_target`
- 其他队友会给出 `move_to_target` 形式的支援跑位
- fallback 很低
- 多个 seed 下表现一致

这说明：

- 一旦进入“我方已控球”的局面，模型已经能把控球推进和无球队友跑位区分开
- 这种输出是有连续性的，不是单步偶然猜对

## Batch 1 Interpretation

从实际输出看，VLM 已经表现出一定作用，但作用范围目前是有限的。

它已经能起作用的部分：

- 识别自由球局面，给最近球员优先建议停球或拿球
- 识别我方已控球局面，让主控球球员继续推进
- 同时让其他球员给出支援型跑位，而不是所有人执行同一条策略
- 在固定典型场景下给出符合基本足球直觉的多人高层意图

它还不够强的部分：

- 默认开局时容易长期停留在“先停球”的保守策略
- 输出目标点仍然偏保守
- 还没有充分体现更成熟的组织进攻能力
  - 例如更主动地利用空位
  - 更明确地让不同球员形成配合
  - 更明确地选择传球而不是持续带球

## Batch 2: Correctness Against Oracle Trajectories

第二批实验是更核心的一批，目标是回答：

- 如果把 scripted multi-player policy 当作标准答案，VLM 和这个标准答案之间会有多大差距

实验方法：

- 用 `SimpleMatchPolicy` 生成 `2v2` oracle trajectory
- 从轨迹中抽取状态帧
- 对每一帧，要求 VLM 给 `home_0` 和 `home_1` 分别输出动作
- 把 VLM 输出和 oracle 动作逐球员对齐比较

这里的 VLM 调用方式是：

- 不是在线 rollout 每步调用
- 而是对抽样得到的单帧状态分别独立调用一次 VLM

本次实验设置为：

- `episodes = 3`
- `samples_per_episode = 6`
- 共 `18` 个采样状态
- 共 `36` 个球员动作预测

主要指标：

- `policy_accuracy`
  - 每个球员的动作类型是否和 oracle 一致
- `step_exact_match_rate`
  - 一整帧里所有 `home` 球员动作是否同时正确
- `target_hit_rate`
  - 目标点是否落在阈值范围内
- `mean_target_error`
  - VLM 目标点和 oracle 目标点的平均误差

本次结果：

- `policy_accuracy = 0.8333`
- `step_exact_match_rate = 0.8333`
- `target_hit_rate = 0.6389`
- `mean_target_error = 1.2773`
- `median_target_error = 0.4738`

按策略拆开看：

- `trap_ball`
  - `15/15`
  - 准确率 `1.0`
- `move_to_target`
  - `15/18`
  - 准确率 `0.8333`
- `pass_to_target`
  - `0/3`
  - 准确率 `0.0`

这批实验说明：

- VLM 在 `trap_ball` 和大多数 `move_to_target` 上已经比较接近 oracle
- 主要偏差集中在更激进的传球决策上

具体来说：

- oracle 在部分开局局面会直接传球
- VLM 更倾向于先稳住、先移动、先控球

所以从“正确性”这个角度看，当前差距并不是“它不会给多人分工”，而更像是：

- 它的战术风格比 scripted oracle 更保守
- 它在早期 `pass` 决策上和 oracle 差距最大

## Combined Conclusion

这两批实验应当这样理解：

- 第一批实验只能说明：
  - 零训练 VLM 不是完全无效的
  - 它至少值得继续做
- 第二批实验更重要，因为它直接给出了和标准答案之间的误差与准确率
  - 这批实验说明当前 VLM 在动作类型上已经接近一个可讨论的水平
  - 但在更激进的传球决策上仍有明显差距

更准确地说：

- 对“自由球处理”“已控球后继续推进”“无球队友支援跑位”这几类问题，VLM 已经表现出可用性
- 如果把 scripted oracle 当作标准答案，当前 VLM 的动作类型正确率已经达到 `83.33%`
- 对“整局稳定组织进攻”这件事，目前证据还不够

因此当前更合适的判断不是：

- “VLM 已经可以直接当完整高层策略”

而是：

- “VLM 已经能作为高层战术建议源，在一些关键子问题上起到作用”

## Bottom Line

一句话总结：

- 第一批实验更多只是初步可行性检验；真正更有分量的是第二批正确性实验。综合来看，零训练 `qwen3vl` 在 `hyperGym` 中已经不是“完全不可用”，并且相对 scripted oracle 达到了约 `83.33%` 的动作类型正确率，但它在更激进的早期传球决策上仍有明显差距。
